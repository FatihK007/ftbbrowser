# ftbBrowser 2.3

Windows browser project built with WPF, WebView2 and .NET 10.

## 2.3
- Modern context menu
- Improved tabs and session restore
- Private browsing
- Download management
- Reader mode, screenshot, PDF and print tools
- Diagnostics and developer tools
- Expanded ftbTools
- 16 built-in games
- Theme support

Windows x64 • .NET 10 • WPF • WebView2
